FAQ

Before you
reach out.

How do we start working together?

Send a project request below or message us on WhatsApp. We schedule a free 30-minute discovery call, then send a written scope and milestone-based quote. There’s no obligation before that.

Who owns the code and IP after launch?

You do, fully. Every project ships with complete source code, documentation and infrastructure under your own accounts. We never hold your product on our accounts or private repositories.

What’s a realistic timeline?

It depends on scope. A focused MVP typically takes a few weeks; multi-module platforms and AI integrations take longer. You get a milestone-based timeline in writing before work starts.

Can you work with our existing team or codebase?

Yes. We can join as an embedded engineering pod alongside your team, or take over an existing codebase for continued development, refactoring or a cloud overhaul.

Do you sign NDAs?

Yes. We sign NDAs before detailed technical discussions on request, and can work under formal data-handling and security agreements.

What happens after launch?

Fixed-scope projects include a 30-day bug-fix window. After that, many clients continue month to month for monitoring, updates and new features — with no long-term lock-in.

// Demo code for illustration — not from a client project
import { Router } from "express";
import { auth } from "../middleware/auth";
import { ProjectSchema } from "../schemas";

export const router = Router();

router.get("/projects", auth, async (req, res) => {
  const projects = await db.project.findMany();
  res.json(projects);
});

router.post("/projects", auth, async (req, res) => {
  const data = ProjectSchema.parse(req.body);
  const project = await db.project.create({ data });
  res.status(201).json(project);
});
